# 沉浸式聖經（Immersive Bible）

和合本．去章節．只留經文 — 國度321空中團契
架構與功能沿用《321領導力》App（同一套 navy／gold 識別、五分頁、PWA）。

版本：**v1.0.4**

- v1.0.4：新增**整卷連讀**——「我的」→閱讀方式可選 分章／純淨／整卷連讀。整卷連讀會把一卷書全部接成連續的文字，沒有任何章題、沒有翻頁，可以一口氣讀完；畫線與進度照常，換模式也不會跑掉。EPUB／PDF 的封面改為直式書封。
- v1.0.3：資料檔缺檔時改顯示看得懂的訊息（原本會冒出瀏覽器的 JSON 解析錯誤）。
- v1.0.2：App 圖示改用封面圖（含 Android maskable 版）；朗讀與陪讀的 Worker 端點／請求格式已照《321領導力》實際程式對齊。
- v1.0.1：人名地名改用《聖經新譯本》現代通用譯名；今日頁換成封面圖 `cover.jpg`。

## 一、這本 App 做了什麼

| 項目 | 原始和合本 | 本 App |
|---|---|---|
| 節號 | 每節前標數字 | **全部去除** |
| 章號 | 每章大標 | 淡雅章題，可一鍵「純淨模式」隱藏 |
| 排版 | 一節一行 | **整章連貫成文**；詩歌體（詩篇、箴言、雅歌、耶利米哀歌、約伯記3–41章）維持分行 |
| 標點 | 舊式 `、` `．` | **新標點**：`，` `。` `？` `；` |
| 用字 | 喫、纔、甚麼、罷、麼、那裡、約但 | **現代通用字**：吃、才、什麼、吧、嗎、哪裡、約旦 |
| 代名詞 | 一律「他」 | 依新譯本用法分「他／她／它」 |
| 助詞 | 耶和華阿 | 耶和華**啊** |
| 人名地名 | 大馬色、西乃、該撒 | **新譯本現代通用譯名**：大馬士革、西奈、凱撒（見下表） |

**刻意不動的**：

### 經文來源與處理方式（重要）

壓縮檔內的 **CUS（简体）本身就是新標點、現代用字的版本**，而 CUT（繁體）是舊版。
因此繁體經文不是手工逐字改，而是**以簡體版為基準、與繁體版逐字對齊後合併**：

1. 兩版逐節對位（31031 節，節序完全一致），學出「繁→簡」對照表；
2. 對齊處：標點取簡體版（新標點），字形取繁體版（正確繁體字）；
3. 差異處：以 218 條人工審訂的對照規則判斷——屬「現代化」的取簡體版（他→她、的→地、那→哪、麼。→嗎？、約但→約旦…），屬「單純簡化字」的保留繁體（資／资、像／象、畫／划…）；
4. 繁體原檔中 6 個缺字（造字區亂碼）由簡體版補回：灶、撐、鬃、蹦、韭、蔥；
5. 人名地名改用《聖經新譯本》的現代通用譯名（逐條查證，見上表）；
6. 最後統一補上：喫→吃、纔→才、罷→吧、歎→嘆、巖→岩、燬→毀、絃→弦、祕→秘、搆→構、甚麼→什麼、儆醒→警醒、約但→約旦、呼格阿→啊（「安提阿」「洗魯阿」等人地名除外）。

**完整性核對**：66 卷 ／ 1189 章 ／ 31031 節 ／ 1,054,263 字，逐章非空，「耶和華」出現 6980 次（與和合本相符）。

## 二、功能

- **今日** — 讀經進度環（/1189 章）、繼續閱讀、今日默想（66 篇經典章輪替）
- **經卷** — 九大分類摺疊目錄 → 章號九宮格（已讀／目前章以顏色區分）
- **閱讀器** — 沉浸式排版、上下章、☰ 回目錄、**淨**（切換閱讀方式）、**A⁺**（四級字級）、**🔊**（朗讀）
- **閱讀方式** — 分章／純淨／**整卷連讀**三段。整卷連讀時一卷書接成一篇連續的文字，沒有章題也不用翻頁；從第幾章進來就捲到第幾章，讀過的章仍會逐章記進度
- **句子畫線** — 點一下畫線，再點一下開底部面板：8 色、寫默想、問陪讀、刪除
- **搜尋** — 全本經文搜尋，命中字句高亮，點擊直接跳到該章
- **陪讀** — 小智 AI，帶入「目前在讀哪一章」的情境，附 10 題 321 理念範例問題，回答可收藏／朗讀／刪除
- **我的** — 統計、字級／主題（自動·日·夜·**羊皮紙**）／純淨模式／註釋顯示／朗讀聲音、我的畫線、我的收藏
- **PWA** — 可加到主畫面，經文讀過一次即離線可用

## 四、部署

1. 在 GitHub 開一個新 repo（例如 `immersivebible`）。
2. 把上列檔案**全部放在 repo 根目錄**（不要建子資料夾——GitHub 手機網頁版上傳會吃掉資料夾結構）。
3. Settings → Pages → Branch: `main` / root → 儲存。
4. 網址即為 `https://<帳號>.github.io/immersivebible/`。

> 每次改動內容或程式，**一定要把 `sw.js` 裡的 `VERSION` 往上加**，
> 否則已把 App 加到主畫面的人不會看到更新。

## 五、朗讀與陪讀（v1.0.2 已對齊實際程式）

端點與請求格式取自《321領導力》app.js 實際使用的寫法，不再是推定值：

```js
const API = {
  chat: 'https://xiaozhi-proxy.spch321.workers.dev',   // {system, messages:[{role,content}]}
  tts : 'https://azure-tts.spch321.workers.dev'        // {voice, rate, sil, silc, sile, text}
};
const TTS_SIL = 140, TTS_SILC = 140, TTS_SILE = 260, TTS_RATE = '+0%';
```

- 朗讀聲音沿用同一批 Azure 真人語音：繁體 **雲哲**（zh-TW-YunJheNeural，預設）／雲帆／曉辰；简体 **云帆**（zh-CN-Yunfan:DragonHDLatestNeural，預設）／云哲／晓辰。
- 陪讀回覆的解析與 321領導力 的 `extractReplyText` 相同，`content[0].text`／`reply`／`text`／`message`／`choices[0].message.content` 都支援。
- 朗讀連不上時仍會自動回落到裝置內建語音；開機會送一次暖身請求，避開 Worker 冷啟動。
- 本沙盒仍無法連到 `*.workers.dev`，以上是用攔截請求的模擬測試驗證「送出的 payload 與 321領導力 完全一致」，真正的線上播放請你在手機上確認一次。

## 六、其他已知限制
1. 「那／哪」「他／她／它」「的／地／得」的分辨，全部採用簡體版編者的判斷；若發現個別節有出入，請指出節號，可個別修訂。
2. 人名地名只替換上表列出、且逐條查證過的項目。若你希望再加（例如「米所波大米→美索不達米亞」或採用新譯本的複合名中點），告訴我要哪幾個，我再加上去。
3. `『』` 引號保留繁體原版（簡體版未使用引號）。
4. 和合本聖經（繁、简）屬公有領域，沒有版權限制。
